# ADR-0002: Garmin 公式 API は使わず、非公式ライブラリを使う

- 状態: 採用
- 日付: 2026-08-10

## 背景

Garmin のデータを取得する手段として、公式の Garmin Connect Developer Program と
非公式ライブラリ `garminconnect` がある。

## 決定

**非公式ライブラリ `garminconnect` を使う。**

利用範囲は「**自分のアカウントの自分のデータを個人利用で取得する**」に限定する。
他人の資格情報を扱う設計にはしない。

## 理由

Garmin Connect Developer Program は法人限定で、個人利用の申請は却下される。
選択肢が存在しない。

## リスクと対策

規約上グレーであること、および非公式であることのリスクを受け入れる。

**2026 年 3 月に Garmin 側の認証変更でエコシステムが一斉に壊れた前例がある。**
ライブラリの破壊的変更は起こる前提で設計する。

| リスク | 対策 |
|---|---|
| ライブラリの破壊的変更 | Garmin 依存コードを `batch/src/personal_coach/garmin/` に閉じ込める |
| レスポンス形状の変更 | `activities.raw` に生 JSON を保存し、後から再パースできるようにする |
| アカウント側の認証変更 | 失敗時に Discord 通知 → 手動でトークンを再取得して復旧する |
| レート制限 | 429 を握って指数バックオフ。初回バックフィルはスリープを入れる |

## 帰結

- 取り込み層とメニュー生成層の間に正規化済みの内部表現を置く。
  メニュー生成が Garmin のレスポンス形状に直接依存しないようにする
- 「動かなくなる日が来る」ことを前提に、復旧手順を [06-poc-notes.md](../06-poc-notes.md) に残す
