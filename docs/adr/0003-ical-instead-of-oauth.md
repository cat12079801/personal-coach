# ADR-0003: Google カレンダーは非公開 iCal URL で読む

- 状態: 採用
- 日付: 2026-08-10

## 背景

当日の予定を Google カレンダーから取得する必要がある。

> **用途が変わった（2026-08-12）。** 当初はスケート予定の有無で筋トレの出し入れを
> 判定するためだったが、そのルールは廃止した。
> 現在は「今日やることを 1 画面で確認する」ための**表示用**として使う。
> メニュー生成のルールには一切影響しない。

## 決定

**カレンダー設定の「非公開 URL（iCal 形式）」を fetch し、`icalendar` でパースする。**

URL は実質的な認証情報なので GitHub Secrets（`GOOGLE_CALENDAR_ICS_URL`）に入れ、
リポジトリには置かない。

## 却下した選択肢

### サービスアカウント

個人 Google アカウントのカレンダーに対しては使えない。
ドメイン全体の委任は Workspace が前提。

### 通常の OAuth

- テスト中ステータスだと**リフレッシュトークンが 7 日で失効**する
- 本番公開にはカレンダースコープの審査が必要
- 個人用アプリのために審査を通す価値がない

## 帰結

- 認証不要、失効なし。運用コストがゼロ
- **.ics は Google 側でキャッシュされ、反映が数時間遅れることがある**

### キャッシュ遅延への対策

前夜遅くに追加された予定を 03:00 のバッチが拾えない可能性がある。

> **アプリ側に「メニュー再生成」ボタンを置いて手動リカバリできるようにする。**

これは省略可能な機能ではない。この決定とセットで必ず実装する。

### 取得失敗はバッチを止めない

カレンダーは表示用でしかないので、取得に失敗しても予定なしとして続行する
（`fetch_events_safe()`）。カレンダーの不調で日次バッチ全体が落ちるのは割に合わない。
